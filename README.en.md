# Creation and Freedom

A Naval Reader · [中文](README.md)

An independent book drawing on Naval Ravikant’s public ideas from 2021 to 2026. Four parts and twelve chapters explore creation, judgment, and freedom, with sources and context.

**[Read in English](https://guojianzhu.com/naval-research-reading/en/)** · **[中文阅读](https://guojianzhu.com/naval-research-reading/)** · **[v2.2.8 downloads](https://github.com/cleardusk/naval-research-reading/releases/tag/v2.2.8)**

The web reader offers language switching, typefaces, a font size of 12–26px (18px by default), pages or scrolling, night mode, and popup notes. Select text to highlight or underline it. “My marks” in Contents lets you revisit passages and export or import backups. Marks are saved in this browser separately for each language. You can undo your last marking action.

Web, EPUB, and PDF editions share the same main text and black-and-white engraving cover. Web and EPUB include 35 notes; PDFs omit notes and markers. Version 2.2.8 updates the title and reading tools; the ideas and prose remain those of v2.2.7.

Ebooks and offline bundles are available through [GitHub Releases](https://github.com/cleardusk/naval-research-reading/releases). Previous downloads remain available. Refresh an older open tab to load the latest reader. Research archives stay local.

This is an independently written book. Naval Ravikant has not authorized or reviewed it.
