# A Study of Naval

[中文](README.md)

An independent book based on Naval Ravikant’s public ideas from 2021 to 2026. Four parts and twelve chapters explore creation, judgment, and freedom, with sources and notes.

**[Read in English](https://guojianzhu.com/naval-research-reading/en/)** · **[中文版](https://guojianzhu.com/naval-research-reading/)** · **[v2.2 downloads](https://github.com/cleardusk/naval-research-reading/releases/tag/v2.2)**

v2.2 includes the complete book and 35 notes in Chinese and English. The web reader supports language switching, typeface and size settings, paged or scrolling layouts, and popup notes. EPUB and PDF editions are available in both languages.

New ebook editions are distributed as GitHub Release assets. This repository maintains the reading website; existing legacy download URLs are retained for now. The research archive stays local.

This is an independently written book. Naval Ravikant has not authorized or reviewed it.
