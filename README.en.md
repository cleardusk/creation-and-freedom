# A Study of Naval

[中文](README.md)

An independent book drawing on Naval Ravikant’s public ideas from 2021 to 2026. Four parts and twelve chapters explore creation, judgment, and freedom, with sources and notes.

**[Read in English](https://guojianzhu.com/naval-research-reading/en/)** · **[中文阅读](https://guojianzhu.com/naval-research-reading/)** · **[v2.2.7 downloads](https://github.com/cleardusk/naval-research-reading/releases/tag/v2.2.7)**

Three readers reviewed v2.2.7 for literary quality, mobile reading, and accessibility and data reliability. The edition restores three points of context and precision and refines both languages. Select text to highlight, underline, or clear marks, saved in this browser separately for each language. Note numbers now have a small circular background.

Web, EPUB, and PDF editions share the same main text and black-and-white engraving cover. Web and EPUB include 35 notes; PDFs omit notes and markers. The web reader supports language switching, typefaces, a font size of 12–26px (18px by default), and paged or scrolling layouts.

Ebooks and offline bundles are available through [GitHub Releases](https://github.com/cleardusk/naval-research-reading/releases). Previous downloads remain available. Research archives stay local.

This is an independently written book. Naval Ravikant has not authorized or reviewed it.
