# Creation and Freedom

A Naval Reader · [简体中文](README.zh-CN.md)

An independent reader of Naval Ravikant’s public ideas from 2021–2026, focusing on AI, making things, judgment, and freedom. Four parts and twelve chapters, with sources and notes.

**[Read in English](https://guojianzhu.com/creation-and-freedom/en/)** · **[中文阅读](https://guojianzhu.com/creation-and-freedom/)** · **[Download EPUB / PDF](https://github.com/cleardusk/creation-and-freedom/releases/latest)**

The web reader offers adjustable type, pages or scrolling, mobile tap-to-turn, night mode, contextual notes, highlights, and underlines. Reading progress and marks stay in your browser; marks can be backed up and restored.

Version 2.4 rewrites the text in Naval's first person, drawn only from what he has said publicly; each chapter closes with a separately marked Editor's note on counterpoints and limits, and there is a new afterword. The EPUB and PDF downloads still carry the v2.3.3 text. PDFs omit annotations. Both languages and an offline bundle are available in [Releases](https://github.com/cleardusk/creation-and-freedom/releases), including previous editions.

The site is built from `content/<lang>/book.md` and `notes.md` with `python3 tools/build.py`; `tools/subset_font.py` re-subsets the Chinese typeface after text changes.
